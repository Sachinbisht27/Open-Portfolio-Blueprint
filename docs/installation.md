# Installation Guide

## Prerequisites
- Python 3.10+
- `pip`

## Steps
```bash
git clone https://github.com/<your-org>/<your-repo>.git
cd <your-repo>
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run
```bash
python run.py
```

## Verify
Open `http://127.0.0.1:5000` and switch language from the header dropdown.
