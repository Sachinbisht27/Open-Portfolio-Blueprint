Case Study

DOST Education: Call Scheduling & Automation Platform

Over three years, I grew from intern to Lead Developer, delivering a mission-critical platform that automates student-parent communication through IVR and callbacks.

Motivation

The project set out to reduce the manual effort required for high-volume calling operations and to raise response rates with smarter callback workflows. It also supports DOST’s mission to transform every home into a playful learning space for families.

Technical Architecture

  • Hybrid cloud on Google Cloud Platform designed for high-volume concurrent IVR calls.
  • Admin Dashboard with Python backend for scheduling, retries, and missed-call workflows.
  • Secure webhook integrations with Exotel and KooKoo to process events in real time.
  • Micro-services for call scheduling, missed-call handling, and webhook processing.
  • PostgreSQL for transactional data plus a custom ETL service into BigQuery.
  • Looker Studio dashboards powered by scheduled queries and curated views.
  • CI/CD via GitHub Actions to Cloud Run and Cloud Functions deployments.
  • Custom alerting with Cloud Scheduler notifications to Slack and email.

My Contributions

  • Led system architecture and designed the full CI/CD pipeline.
  • Built the call scheduling engine, secure webhook handlers, and database query optimizations.
  • Introduced monitoring, alerting, and auto-retry for traffic spikes.
  • Mentored junior engineers and owned production release cycles.

Scale & Impact

  • 90,000+ active users and 600,000 total platform users.
  • Reduced manual operations workload by ~70%.
  • Improved callback success rates with automated workflows.
